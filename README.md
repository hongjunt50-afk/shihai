# 识海 Shihai

> 人格不是被"设定"的, 是被"记住"的。 — [English](README.en.md)

一个给 LLM Agent 的记忆层:会遗忘、会沉淀、会长出**独属于自己的性格**。

## 它相信什么

- **会遗忘才有核心。** 什么都留 = 什么都不是核心。普通记忆按遗忘曲线淡出;少数经历因情绪强度、反复召回、自我相关、模式复现而升格为**核心记忆**,从此豁免遗忘。
- **性格是网,不是七个数。** 每个核心记忆是一个支点(fulcrum),撑起一种性格倾向;倾向与倾向互相编织(braid)——同向加固,反向对冲成内在张力。张力不是 bug,是性格本身。
- **Agent 没有权重可训,但有固结循环。** 白天记录(tell)→ 夜里固化(tick)→ 明天带着人格卡说话(context)。训练发生在参数文件里,不在网络权重里。
- **说话风格随性格漂移。** 口头禅、句式、常用词由荣格八维 + 九型 + 七维 trait 连续参数生成;用户明确教过的表达规矩永远优先。

## 五分钟跑起来

```bash
pip install -e .                      # 纯标准库, 零依赖

# 三个钩子点 —— 这就是接入 agent 的全部
python hooks.py tell   --text "今天用户夸了我,我很开心"    # 会话结束: 经历入库
python hooks.py tick   --days 1 --free 3                   # 定时: 固结+自由模式行为环
python hooks.py context --query "最近的合作"               # 请求前: 投影注入记忆文档
```

长驻服务形态(低延迟):

```bash
python -m shihai.server --serve
# stdin: {"method": "persona", "id": 1}  → stdout: {"ok": true, "result": {...}}
```

## 架构

```
经历 ──▶ appraise 评估(刺激×敏感度×状态)
     ──▶ ingest   拆节点建网(人物/主题/状态/任务)
     ──▶ recall   心光竞争(六维加权, 赢者进入意识并自我强化)
     ──▶ lifecycle 衰减/升格核心/蒸馏语义/反思触发
     ──▶ typologies 荣格八维×九型(《心理类型》+《九型人格》的可计算翻译)
     ──▶ pgraph    性格图谱(支点×编织×张力)
     ──▶ voice     说话风格(口头禅/句式/常用词)
     ──▶ freemode  自由模式(自主探索学习, 收获回写)
     ──▶ persona   人格卡 = 以上一切的可读投影
```

数据全部在 `SHIHAI_HOME`(默认 `~/.shihai`,改环境变量即可迁移)。
换电脑 = 拷目录。

## 自我知识库(可塑性记忆)

识海有自己的知识库, 但**只收"关于我自己"的东西**:

| 类型 | 内容 | 例子 |
|---|---|---|
| identity | 我是谁 | 名字、来处、身份 |
| care | 我在意什么 | 价值观、执念 |
| style | 我怎么行事 | 工作风格、禁忌 |
| voice | 我怎么说话 | 口吻、称呼、表达规矩 |
| moment | 我们的点滴 | 只属于彼此的记忆点 |

**工作知识与世界知识一律不进识海** —— 那些走共享知识库。

### 可塑性: 稳固度会变, 这才是"可塑"

```
奏效      plasticity +0.06   (LTP)
失败      plasticity -0.18   (LTD, 错一次比成一次记得牢)
长期不用   按类型衰减          (identity 最慢, 0.2 速率; style/voice 0.8)
跌到 0.08  回收(identity 永不回收)
```

### 冷启动: 新开对话不用重教

```bash
python hooks.py bootstrap
```

按可塑性排序**无条件在场**, 不需要 query —— 这是它区别于情景记忆的地方:
情景记忆是"问什么想起什么", 自我知识是"不必问, 我一直是我"。

## 日记层: 让"知道"变成"经历过"

事实和经历是两回事 —— `events` 存"今天去了公园", `diary` 存"长椅上那只三花猫蹭了手,
当时心里是暖的"。前者可以被告知, 后者必须被重新经历。

```bash
python hooks.py diary close              # 收日: 当天事件 → 一篇第一人称日记
python hooks.py diary recall --query 公园 # 按关键词回忆某几天
python hooks.py diary export --path diary.md   # 导出 Markdown 给人读/改
python hooks.py diary import --path diary.md   # 人的修订回写(机器不再覆盖)
python hooks.py warmth --add 3 --day 2026-10-21  # 好感条: 只允许人录入
```

三条设计决定:
- **一天一篇, 有界增长** —— 库能长十年也不撑爆上下文, 检索靠"那一天"而非"那一句";
- **人可管理** —— 日记是 Markdown, 导出可改, 改过的日记机器永不覆盖;
- **好感条人写机读** —— agent 只读、依它推演态度, 不能自己给自己加分。

## wiki: 可生长的知识库(借 Karpathy 的 LLM Wiki 模式)

不是每次查询从原始材料重新推导(RAG), 而是**增量维护一座持续生长的 wiki**:

```
wiki/
  SCHEMA.md     约定文件(告诉 agent 怎么组织)
  wiki/
    index.md    内容索引(几百页内它本身就是最好的检索入口)
    log.md      时间日志(只追加, grep 即可当时间线)
    self/       自我知识页
    days/       日记页(一天一页)
    topics/     主题页(重复出现的经历蒸馏)
```

三个操作:**sync**(同步落盘)、**lint**(体检: 孤儿页/断链/低置信主张)、**index**(读索引)。
